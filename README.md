# ChillSubs extensions

Latest build of the ChillSubs browser extensions (auto-published).

## Install / update

- **Windows:** download [update-extensions.bat](https://raw.githubusercontent.com/niyatimadaan/extension-releases/main/update-extensions.bat) (right-click → Save link as) and double-click it.
- **macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/niyatimadaan/extension-releases/main/update-extensions.sh | sh`

Extensions are extracted to `~/chillsubs-extensions/`.
First time: open `chrome://extensions`, enable Developer mode, click **Load unpacked** and pick each folder.
After each update: click reload on both extensions.

Direct zip: [chillsubs-extensions.zip](https://raw.githubusercontent.com/niyatimadaan/extension-releases/main/chillsubs-extensions.zip)
